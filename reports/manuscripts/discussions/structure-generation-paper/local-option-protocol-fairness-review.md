# 局部结构备选协议：公平对照与可证伪条件

日期：2026-10-21。性质：独立、限定范围的静态协议审计，不是已采纳协议、方法创新验收或模型效果证据。本轮只写本文件；不调用被测模型、HDL、solver，不运行代码实验，不改实现、任务、评价、论文正文或旧记录。N15仍暂不实施。用户允许的范围是少量保持顶层功能的模块分解/接口变体，不能据此增加资源、潜伏期、流量假设或新的算术目标。

**结论：可以保留一个待检验的系统假设，但不能从候选乘积或旧有限域诊断推导实际收益。** 假设是：在同一公开输入、同样的规划与行为预算上限内，一次局部备选规划加事前组合，能比最强的压缩完整方案规划或直接构造，取得更高的首次项目成功率，或在成功率满足预定非劣条件时降低完整成本。收益必须来自实际输出质量、表示成本或交接工作，不能只来自给一个组更多候选、更多事实或额外阶段。本轮没有运行这个比较，也没有取得足以重新登记独立核心的证据。

## 2. 比较对象与覆盖含义

共同公开输入记为`I`，包括需求、允许的结构承诺、接口/数值事实和同一可取得的原语信息。一次规划原件记为`O`。解析后的局部池为`P1,…,Pm`；一个完整结构`z`必须给出所有生效决定。`C(I,z)`是事前可执行的公开结构条件，`S(z)`是预定的确定性选择顺序。`C`不自动代表全部功能正确性，也不能接受模型自报属性作为可信事实。

“同池全局候选全集”是从同一`O`可合法实例化的所有完整结构：

```text
Z(O) = { z：每个生效选择来自O，所有条件依赖、共享声明和接口均一致 }
F(O) = { z∈Z(O)：C(I,z)成立 }
```

这不要求`Z`是简单笛卡尔积。不同分解可能改变模块数、接口、下游生效决定以及共享状态责任；必须表达选择条件和成组片段，不能把互斥子树拆成互相独立的槽。如果这些条件尚未可信落地，程序只能报告检查未覆盖，不能把任意拼接称为可组合结构。

若完整方案集合`G`确实来自同一`O`，且`G⊆Z(O)`，则`G`中的可行方案也在`F(O)`中。这只是同池集合包含关系。只有`F(O)`含有`G`之外的可行结构、选择器能够找到它，重组才可能扩大这次规划的可行覆盖。若强全局基线已经取`G=Z(O)`，使用相同`C`、`S`和完整搜索，两者应返回相同结果；差别只能另测实现时间、内存、工作量等。

对独立生成的“局部池输出”和“完整方案输出”，两份`O`不同，没有上述集合包含保证。不能用假定各局部正确率独立的乘积公式，预测实际LLM、其相关错误或最终RTL成功率。局部池覆盖一个结构也不意味着选中结构的行为更容易一次实现；只看覆盖会遗漏选择偏好和行为难度。

规范化与去重规则须事先共享：稳定ID、类型、连接和已支持的数学摘要可用于剔除重复，单纯改名不算多样性；未建立语义等价检查时，不能宣称已精确去除了所有功能等价结构。各组均不得靠重复输出增加“候选数”。

## 3. 什么可能产生优势，什么会消除优势

| 可能有利的条件 | 必须同时核对的抵消因素或反证 |
| --- | --- |
| 一次输出能保留互补选项：不同完整草案各有正确片段，交叉组合存在可行结构 | 同一次模型输出可能共享错误的顶层理解、系数、边界或缺失选项。一个必要选项在任一池缺失，程序不能凭组合创造它。不能把局部独立性当事实。 |
| 大部分合法变化可以用少量共享声明和局部差异表达 | 强完整方案基线也应复用相同声明、选项字典及索引向量，不能被迫反复输出完整RTL或冗长JSON。若一个短索引向量就能表达完整方案，压缩差距可能很小。 |
| 已有公开条件能在行为前廉价排除不一致组合 | 若约束需要人工补完、候选模型自证、隐藏评价或行为后的工具反馈，收益和信息边界即改变。若条件已足以直接构造一个合法答案，模型提池可能反而多余。 |
| 局部备选含有跨完整草案可复用的共同语义 | 接口编码、切分、共享状态或多输出相关性可能要求整组选择；成组后有效决定数下降，候选乘积缩水。遗漏依赖产生的是非法覆盖，不是多样性。 |
| 备选表比同预算完整提案列表更容易生成且不截断 | 备选ID、重复类型、依赖、局部合同、来源和排名都会消耗token；更长响应也可能挤掉行为预算或增大解析失败。解释文字不应成为一组独享的额外提示。 |
| 公开排序能选中适合行为生成的结构 | 最少备选数、模型排名或最小模块数不等于功能成功概率。新增跨组合也可能比模型原提案更难实现，抹去覆盖收益。不得用私有终点评价选择排名。 |
| 程序组合和严格发射的成本小于节约的规划/失败成本 | 条件依赖可令搜索和核验变贵；精确结构保护、适配、局部语义审阅及更多模块的生成开销都需计入。旧协议的≤64赋值不能外推为开放分解仍同样小。 |

不需要各局部统计独立才能有系统收益；确实发生的互补覆盖加廉价可信选择就可能足够。反过来，备选数很多、输出相互不同或存在一个手写重组例子，都不足以证明这些条件在目标任务上出现。

实际资产对这组条件的限制很强：旧FIR连接的完整合法链只有两条，普通构造已全部得到；fork的完整通道须原子处理。N10 TD的R切分与E切分改变下游接口和局部函数，不能只拼接两份模块名单；按已有AST节点分组便可产生两种。N10 FIR/TD没有必须优选某种分解的额外目标。因此它们可检验交接和拒绝错误组合，却尚未证明局部选项比直接返回F-A/T-A有实际收益。这里不再加PPA、时序或协议条件来制造优势。

### 3.1 后续同型接口静态资格：有语义耦合，不等于协议获益

主审随后封存的[静态计划](../../../../artifacts/responsibility-local-semantic-options-static-20261021-01/plan.md)、[人工fixture](../../../../artifacts/responsibility-local-semantic-options-static-20261021-01/fixtures.json)和[结果](../../../../artifacts/responsibility-local-semantic-options-static-20261021-01/results.json)补充了两项更明确的耦合。本轮只读这些文件，没有重算；它们尚未冻结为正式模型任务。

| 同型局部选项 | 匹配与错误组合 | 公平解释 |
| --- | --- | --- |
| FIR：`P0=3*x0`、`P1=3*x0-x1`；`Q0=-2*x1+x2`、`Q1=-x1+x2`；P/Q均signed6；父输出`wrap7(P+Q)` | P0/Q0和P1/Q1合法。交叉组合位宽合法但改变x1系数；在`(x0,x1,x2)=(0,1,0)`，正确−2，两交叉结果为−1、−3。edge输出保持原函数。封存结果覆盖4096个输入。 | 区分数学兼容与仅类型兼容，不能用纯宽度首选作唯一强基线；普通线性表达式组合即可检查。固定P0/Q0（AA）仍是合法直接构造。 |
| TD：producer保留R/E输出，signed8桥取`E`或原`D=sat8(floor(alpha*E/16))`；consumer取apply或final，分别算`sat8(value+sat8(floor(alpha*bridge/16)))`或`sat8(value+bridge)` | E/apply、D/final合法。`reward=0,next=16,gamma=16,value=0,alpha=8`时，正确R=16、E=16、D=8、U=8；E/final给16，D/apply给4。原sat位置与顶层R/E/U不变。封存数字只覆盖5个value层级的327680个可嵌入公开输入，不是TD全域证明。 | 桥的相同ABI不携带“这是E还是D”的充分语义；需要实际表达式/可信语义绑定。固定E/apply仍合法且强。不能因为有两个合法匹配就称为新选择算法。 |

这两例没有模型偏好、池缺项、token或首次RTL结果，不能据此声称H-cover/H-system成立。如果模型只给桥名、角色标签或自报公式，程序还须有可信来源与语义绑定，才能将其用于组合检查；声明正确不证明生成body正确。若直接给出上述完整数学选项，普通表达式组合/精确编译也得到同一兼容关系，需公平共享。这里的增量仅是静态资格更能暴露类型过滤的不足，不是已测的新协议效果。

四格矩阵本身也不是“局部重组胜过完整采样”的见证：若完整提案原本就是两个匹配组合，完整方案选择已经成功；若人工只选两个交叉错误组合再允许重组获解，证明的是这个手工集合的包含关系。实际模型是否提出这种互补片段，以及压缩完整方案输出是否同样能直接提出匹配组合，都仍未测。

## 4. 同一次LLM输出的最强匹配对照

这些控制只解释一个已冻结输出`O`上的处理差异。它们不重新调用规划模型，不用独立评价筛选结构，也不把多次消费同一缓存算成多份模型样本。

| 控制 | 取得的信息与具体处理 | 能支持的结论及边界 |
| --- | --- | --- |
| L：待审局部组合 | 全部`I/O`，执行同一解析、依赖、`C`和`S`，从局部池选择一个结构 | 是协议的选择部分；仅这一行不是端到端模型方法。 |
| G-all：最强同池全局候选 | 全部`I/O`，把`Z(O)`中的完整赋值当全局候选；同一`C/S`，允许惰性展开、约束传播和去重 | 与L同能力的强标准控制。小域完整覆盖时选择应一致；若不同须查条件、排序或搜索预算，不可先称方法优势。无需为每个完整赋值再付费调用LLM。 |
| G-explicit：明确完整提案，禁止重组 | 全部`I/O`，只在模型确实标明为完整提案的结构集合`G`中筛选，使用同一`C/S` | 只测“从这些明确提案跨组合”的增量。若原输出没有完整提案标识，此控制不可从各组第k项硬凑，状态是不可构造。也不是最强同池基线。 |
| G-derive：程序直接构造后按池过滤 | 同一`I`和`O`中共享声明，以普通匹配、链构造或可取得的AST outlining生成合法完整结构，再按同池选项和同一`S`过滤 | 具体核对组合是否被便宜构造覆盖。旧fork/FIR已经存在这种控制；不能用不回退的弱贪心代替。新变体adapter若未实现，必须标为计划。 |
| L-first：逐项首选/固定贪心 | 全部`I/O`，只改变选择策略，最终仍由同一`C`接受或拒绝 | 失败可解释跨组条件的重要性；胜过它不能代替G-all、G-derive或完整规划竞争者。 |

`G-explicit`若要在新共同输出中出现，需事先要求模型明确提交少量完整索引向量，并计入规划输出预算；L也能看到这些向量。这个共同输出可隔离“能否跨提案重组”，但它已经改变原规划任务，不能同时作为纯局部格式与纯完整格式的效果对照。另一种从完整提案提取局部池的控制，同样只能说明对这些提案的重组作用，不能证明原生局部池更易生成。

若L和G-all最后得到字节相同的规范化结构，可以共享一次相同的行为响应和评价，隔离选择器差异；该响应只是一份相关证据，不能按控制数增加样本数。若结构不同，不能把一个结构的body硬接给另一个结构作为公平行为控制。是否需要分别生成行为及其资源上限，须另行授权；本轮不执行。

## 5. 真正检验局部输出协议的端到端竞争者

共享缓存不能回答模型在不同输出格式下会怎样分配有限预算。最小公平竞争需让下列两条路线各自从同一`I`开始，并在同一终点结束：

1. **局部路线。** 一次规划给有限局部选项及必要依赖，程序选择并固定一个结构，最多一次行为生成。
2. **压缩完整方案路线。** 一次规划给预算允许的完整结构；共享模块/选项字典，完整方案用索引或差异表示。与局部路线使用相同公开结构检查、排序、程序发射和结构保护，最多一次行为生成。完整方案可以是一个或多个，不能人为只准一个而把候选数量差异称为格式收益；也不能免费反复采样直到填满。

双方均应看到相同公共需求与可取得的约束规则。除输出要求及其必要语法说明外，示例、语义解释和“避免哪类错误”的提示应一致。格式本身新增的token是处理成本，不是可隐去的固定项。可用相同预算上限下的实际成本/结果比较；不要求把所有输出填充到同长度，也不要求双方生成相同候选数。

完整方案的每个向量可以表达联合依赖，不必把其偏好限制成逐项排名之和。选择器消融用同一`S`隔离处理差异；端到端强竞争若允许模型给整体排序，就须给双方相同的排序表达权限，或事前采用同一结构目标/规范化并列规则。排序若不同，应作为协议差异披露，不能称为只有“局部/整体表示”一个变量。

还需要**不受LLM池限制的直接构造/编译竞争者**：同一公开函数/接口要求输入，固定返回一个允许的结构，或用可取得的普通规则构造。它不需要覆盖全部合法组织；现有目标只要求提交一个正确项目。N10可具体使用F-A/T-A或已列出的AST outlining，不把尚未完成的frontend标成实测实现。若它需要更强的人工作业、人工AST翻译或库适配，逐项记录；若局部路线也吃同一AST，这项输入必须共享。若局部路线吃自然语言而编译器吃人工转换AST，必须把转换计入，不能声称输入相同。

隔离结构协议时，可以让直接构造的结构也经过同样的一次行为生成。若比较最终部署成本，则还应承认完整数学编译可以省去行为调用，不能强迫它浪费调用后才宣布本方法成本相同。两者分别是受控结构比较与原生端到端竞争，不能混算。模板先前开发和新任务适配的人工成本不能藏去；本轮不假定其工时与新协议相等。

“同候选数”与“同资源预算”是不同问题。前者可作有界诊断，核对选择器是否因多检查结构而获益；主效率问题应固定资源并允许表示压缩决定可提出多少结构。不能一方面将隐式乘积称为本方法利益，另一方面禁止全局强基线廉价展开同一信息；也不能把指数个赋值说成指数次API调用。

## 6. 预算、行为交接与失败必须一起匹配

建议比较单位是一条从公开需求到封存首次项目的完整尝试，而不是一份合格池或一项被接受结构。下面只是待注册的设计要求，不是新增运行授权。

| 维度 | 公平约束 |
| --- | --- |
| 阶段 | 两条LLM路线都是一次规划、至多一次行为。共同程序检查可以选择和发射，但不能把诊断回送模型；增加约束解释调用、澄清调用、修格式或重采样均须计费且会改变当前协议。 |
| 规划/行为资源 | 分别固定同模型/版本及各阶段调用、输入/输出与可计量推理token、超时和费用上限，并固定总上限；不能让一组从行为预算借给规划而另一组被禁止。若另研究总预算下可变分配，应预定相同策略权限，不与固定分配结果混报。 |
| 程序资源 | 相同检查能力、公开约束、搜索时限/节点上限及失败处理；允许竞争者采用更高效的标准传播/构造。计算、编译和保护成本计入完整成本，不把它们都称为免费后处理。 |
| 行为输入 | 发射相同规范的选中结构、端口和必要局部数学。不得只有局部组保留全部备选解释/额外语义提示；若保留则属于整个协议的信息差异，需公开并由信息匹配控制拆开。 |
| 结构锁定 | 相同精度保护实际实例、接口、接线及行为可写面。body绕过或重构选定结构时，不能用功能通过掩盖处理变量消失；具体缺口见连接裁决§7。 |
| 失败 | 格式错误、截断、缺组、非法选项、无可行结构、搜索超时、发射失败、body违规、功能失败都留在全部预定尝试分母。重复项按事前共享规则去重，或在共同格式明确拒绝重复时记失败，不能事后择利解释。无解仅是该池/该次尝试无解，不是原需求不可实现。工具基础设施问题另列但不静默删除。 |
| 实际与上限 | 记录实际耗用和预算上限。规划失败而未生成行为，实际行为耗用为零，不浪费一次调用补齐；也不把省下的额度自动换成额外尝试，除非两组事前有同样的固定总预算策略。 |
| 缓存与人工 | 消融可复用原件；估计独立运行成本时，每条路线须承担其本来所需的池生成成本，不能除以消融组数。记录格式设计、语义标注、适配、审阅和确认工作；未测工时就保留未知。 |

最终评价使用同一可信版本，结构选择不得读取其私有内容或评价结果。不能为所有结构各生成body，再用最终通过者代表“一次行为”；也不能先看成功率再决定保留哪个规划重复。相同随机种子不能保证模型输出误差独立或严格配对；任务、公共输入与预定重复可配对，依赖关系应保留。

## 7. 最小可证伪假设与证据链

**最小机制假设H-cover：** 在预定、共同公开的少量结构变体上，一次预算受限规划确实产生互补的有效片段，使严格依赖约束下存在模型明确完整提案之外的可行结构，且这些结构可在同一程序预算内被找到。它需要真实原件中的选项、完整提案归属和依赖见证；若没有明确完整提案归属，只能描述池内覆盖，不能计算“超出原完整方案”的比例。G-all应复现这项覆盖，因此H-cover验证的是重组现象，不是独有求解能力，也不是充分的论文主效果。

**最小系统假设H-system：** 在相同预算上限和首次无反馈协议下，局部路线相对压缩完整方案路线和具体直接构造，能改善最终首次功能成功，或在事前声明的非劣条件下减少实际完整成本/人工交接负担；增益不能被额外信息、阶段、候选调用或不对称失败处理解释。非劣界、成本口径、任务选择及停止预算须在结果前确定；本轮不臆定样本量、界值或预期提升。

最小证据链应分开报告：

1. 全部规划尝试中，多少输出可解析；去重后有多少真正不同的有效局部选项、全局结构和条件组，而非多少文本条目。
2. 哪些池有公开可行结构；被选结构是否与G-all/G-derive一致；新组合来自何处；缺选项、相关错误或成组依赖在哪一步阻断。
3. 已选结构能否被严格固定、一次body是否遵约并通过相同独立功能评价；规划可行但行为失败必须保留。
4. 全部尝试的实际token、费用、程序时间、失败开销及适配/确认负担。主终点按完整尝试记账，条件于“池已合格”的统计只能作机制诊断。

若最终成功提高却无重组见证，仍可能是提示或输出格式的作用；不得宣称组合覆盖导致改善。若仅相同成功而实际成本下降，可以检验系统效率贡献，无需证明标准工具不能得到相同答案。若两者均未改善，则不以“隐式方案更多”救回主张。

## 8. 停止条件与当前裁决

1. **任务退化：** 相同公开目标允许一个廉价固定构造完成，而局部协议未识别要减少的具体工作。当前N10 FIR/TD属于尚未摆脱这个风险的资格题；多个合法结构本身不够。
2. **重组退化：** 有效选择必须整体成组，或真实池缺少必要片段，导致与明确完整提案无覆盖差异。停止“组合覆盖优势”主张；是否另有表示成本收益须有独立测量。
3. **公平性失效：** 只有靠更长提示、更多规划/行为调用、反馈选择、私有条件或不计失败才出现优势。先停止比较并修复设计，不能晋升结果。
4. **语义/保护缺口：** 组合只满足接口外观，关键兼容性仍由模型自报；或body可改变所选结构。停止功能/归因主张，不用更多模型样本补证。
5. **强竞争无收益：** G-all相同并非单独停止理由；但若压缩完整规划/直接构造达到相同或更好首次结果，且未见成本、适配或审阅收益，则停止当前独立协议核心，不继续更换排序/示例直到获胜。
6. **补工超限：** 需要新语义库、通用RTL理解、任务环境放宽或大规模新任务才能形成差异，不再满足本轮最少补工目标；先保持边界，不自行扩题。

因此，本轮裁决是：**公平的研究问题可以精确定义，实际优势与新增系统交接仍未建立。** 保留H-system作为未执行、可被否定的假设，不恢复旧连接候选的开发资格，也不从标准等价推出系统没有研究价值或SCI方向不可行。后续若没有具体、非退化任务和可执行同信息强对照，本报告本身不构成模型pilot或新核心开发的理由。
