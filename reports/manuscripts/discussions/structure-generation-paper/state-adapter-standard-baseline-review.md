## 2. 公平起点必须包含相位事实

固定本轮二值TFF：复位令q清零，否则q_next=q XOR u。令d1…d9为八位数据加校验位，目标p=d1 XOR … XOR d9。两流程同等获得组件递推、公共需求，以及以下可信信息；不能只给基线端口名。

| 必须明确的输入 | 缺失时的影响 |
| --- | --- |
| 哪九个时钟边沿属于目标窗口 | 递推自身不识别帧或数据位。 |
| 首个目标采样前如何清零 | 同边沿优先复位可能丢首位；初值未知也会污染累计。 |
| 最后校验采样与提交间还有哪些更新 | 额外输入可能再次改变q。 |
| 读取边沿前旧值、边沿后新值或捕获寄存器 | 三者不能混称“完成时状态”。 |
| 错误停止、全局复位、下一帧与提交的关系 | 本轮单帧代数不定义完整接收器。 |
| 消费者如何解释该状态 | 原始q与经反相解码后的值可能都合法。 |

这些信息来自任务/组件的可信语义声明；将自然语言转成窗口、从任意RTL抽取递推均未实现。不能把待建的前端描述成C34已具备能力，也不能用未知人工成本主张已省工。

## 3. 同信息普通构造已覆盖当前两项适配

无复位的一段更新直接展开为：q_read=q_initial XOR 所有读前u的异或。因q XOR 0=q，普通控制可令u=W ? in : 0，其中W准确选中九个采样；若初值0、读前不再复位，q_read=p。另一普通方案在停止边沿捕获旧q，前提是该旧值已恰好累计九位。这些是由给定递推与窗口得到的手工构造，没有实现或测试通用合成器。

以下四格只假定：停止边沿前q=p、停止输入为1、该边沿不复位、读取发生在任何后续更新之前；“直接读”按原始1代表奇校验合格解释。

| 停止边沿输入屏蔽为0 | 停止边沿捕获旧q后读捕获值 | 直接读停止边沿后q |
| --- | --- | --- |
| 否 | p，满足目标 | p XOR 1，按上述原始解释会颠倒判定 |
| 是 | p，满足目标 | p，满足目标 |

**补充合法做法：** 不屏蔽也不捕获，若显式把停止边沿后q反相解码，同样恢复p。故N34所定位的是“不补偿却把后读原始q当p”的错配，不是所有后读实现均错误，也不是屏蔽/捕获二选一的唯一正确结构。读得更晚、错误停止或额外复位须另行分析。

以上只是二值静态代数和相位表，不是四次运行、Verilog X/Z等价或完整UART证明。原题允许九位捕获后归约，也允许融合逻辑；强对照必须保留这些合法实现，不能为制造适配工作而强制使用可选TFF。

## 4. C34裁决与重新进入门

当前“从可信递推和窗口得到中性输入/旧值捕获”的具体步骤已可由上述普通控制规则完成。C34尚未界定更广支持集、自动语义获取、资源选择或认证流程；也未有证据表明同等输入下减少了真实完整工作量。Greaves/Nam源码可得性未知不能替代这项差异。因此，本轮停止为**当前版本**追加原型或模型pilot，保留公开相位案例和强对照规则作为检查资产。

沿用[N33比较标准](comparison-endpoint-audit.md)：标准方法具有同等能力不自动否决系统贡献。重新进入须同时具备：

1. 真实必要案例及完整公开语义；不靠自行强加组件复用、并发或PPA目标制造需求。
2. 明确的一步额外处理，或具体可否定的成本/可靠性机制；写清双方谁提供窗口、递推和其他真值。
3. 同信息强对照的实际路径，允许正确解码、归约、普通控制或通用合成；输入准备、失败和后续行为生成均进入端点。
4. 足以支持小规模资格的固定范围与验收条件；任务采纳、可信评价及被测运行按各自授权处理。

本轮没有满足上述重新进入条件。下一轮优先寻找真实未解决的生成交接需求及可观察的额外步骤，不继续围绕这一位奇偶例加包装，也不将“未找到完全同款论文”视作创新成立。N24的不同系统定位仍待用户选择；此裁决不替代该选择。
