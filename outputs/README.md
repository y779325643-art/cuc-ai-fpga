# 演示与参考输出

本目录保存项目展示、制作源文件和研究笔记。历史材料中的 HNAI-FPGA 名称和内容保留原貌。
当前工程状态见 [current-status](../docs/current-status.md)，研究规范见[规范索引](../docs/specs/README.md)。

| 入口 | 内容 |
| --- | --- |
| [presentations/](presentations/README.md) | 五组演示材料，按项目区分源文件与成品 |
| [project-notes/](project-notes/README.md) | 项目说明和 IR 讨论摘录 |
| [literature-review/rtl-llm-reading-notes.md](literature-review/rtl-llm-reading-notes.md) | RTL 与语言模型阅读笔记 |

制作脚本放在各项目的 `src/`，演示成品放在 `deliverables/`，已有文本素材放在 `sources/`。
预览、排版和 QA 中间目录继续由根目录 `.gitignore` 忽略。本地忽略的输出不列入共享索引。
候选工程、运行日志和机器评测报告写入 [artifacts/](../artifacts/README.md)。

这些材料不构成当前研究规范或正式评测证据。旧路径与迁移规则见
[结构迁移记录](../docs/migrations/repository-layout-2026-09-24.md)。
