# Superpowers Docs Index

This directory stores design specs, implementation plans, and decision logs
created through the brainstorming -> spec -> plan workflow.

## How To Read

- Read `../current-status.md` first to identify the active work.
- Read only the newest relevant spec/plan for the current slice.
- Treat older plans as execution history, not live instructions.
- Do not edit completed step-by-step plans just because code has moved on.

## Subdirectories

- `specs/`
  - Approved designs and research design records.

- `plans/`
  - Detailed implementation plans, mostly historical after execution.

- `decisions/`
  - Decision logs explaining tradeoffs and reasoning.

## Non-Core Historical Work

Presentation and deck-redesign docs from 2026-06-04 are retained for traceability
but are not active SR2FPGA data-agent guidance.
