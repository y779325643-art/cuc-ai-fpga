## 版本关系的关键结论

1. `paper1-v2.3` 是当前案例修订，方法与证据规则继承 v2.2；它与 PC 格式号属于不同版本轴。
2. `system-his-v1.2` 仍由旧流程使用；`pc-decisions-v1` 是向旧 HIS 组装器提交决策的接口，不是一个名为 PC1.0 的新格式。
3. `sr2fpga-pc-2.0` 留作未采纳的设计草案，未注册，也没有当前执行入口；无需经过它才能运行 PC2.1。
4. `sr2fpga-pc-2.1` 有实际输入、checker、emitter 和六方法开发执行器；旧结果不能靠改版本字段变成新结果。
5. FPP 的 `project-package-v1`、轨迹/训练视图的 v1/v2、停止结果的 v1/v2/v3 各自独立演化；“选最新数字”不能代替检查生产者和消费者。

详细版本表、函数调用和机器注册位置见[03](03-contracts-hardware.md)与[07](07-contract-registry.md)。
